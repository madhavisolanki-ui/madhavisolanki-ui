## 🚀 Featured Projects

### **1. AI Resume Analyzer** | *NLP-Powered Talent Acquisition*
**Tech Stack:** Python | Streamlit | NLP | Pandas | scikit-learn  
**GitHub:** [View Repository](https://github.com/madhavisolanki-ui)

**Problem:** Manual resume screening is time-intensive and introduces bias in the hiring process.

**Solution:** Architected an end-to-end resume processing pipeline with:
- **Intelligent parsing** using regex and NLP to extract structured data (contact, experience, education)
- **Skill extraction** against standardized skill taxonomies with validation
- **ATS-score computation** for resume-job matching using TF-IDF and cosine similarity
- **Actionable feedback generation** for candidates with improvement suggestions
- **Interactive Streamlit dashboard** for recruiter workflows with real-time filtering

**Impact:** 
- ✅ **80%+ accuracy** in skill extraction (validated on 500+ manually-labeled resumes)
- ✅ Reduced manual screening time by **~65%** (from 3 hrs to ~1 hr per 100 resumes)
- ✅ Processed **2,000+ resumes** across pilot organizations
- ✅ Improved hiring fairness by reducing unconscious bias
